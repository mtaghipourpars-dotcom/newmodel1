# Phase Checklist

For each phase, record:
- Gate and work-package ID.
- Source documents read.
- Expected outcome and non-goals.
- Files to change.
- Risks and unresolved decisions.
- Tests and expected evidence.
- Actual commands/results.
- Screenshot or artifact links.
- Data-integrity assertions.
- Ledger update and next-gate decision.

Stop before code edits if the visual reference cannot be inspected, required internal data is absent for a claimed real-data feature, or a business rule is ambiguous.
