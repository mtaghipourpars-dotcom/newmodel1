# PARS Real Data Boundary

## Purpose

Prevent the Demo MVP from becoming visually impressive but factually fabricated.

## Verified official product data

The PARS official product catalog lists product families including:

- Thermal power-plant generators
- Industrial generators
- Hydro generators
- Wind generators
- Wind turbines
- Induction motors
- Permanent-magnet motors
- Busduct

Examples verified from the official catalog include:

- MGG72-SH2 / MGS72-SH2 — 376 MW active power
- MGG63-SA2 — 238 MW active power / 280 MVA apparent power
- MGS58-SA2 — 200 MW active power / 250 MVA apparent power
- MGH61-SA32 — 250.2 MW active power / 278 MVA apparent power
- MGW13-IA6 — 2.56 MW active power
- MWT2.5-103-G-I / G-II — 2.5 MVA
- MWT4.5-126-G-I — 4.5 MVA

Source: official PARS product catalog:
https://mapnagenerator.com/Fa/Products

## Data that is NOT currently available from public sources

The following must not be fabricated:

- Current PARS project list
- Current project progress
- Project margin
- Project cash exposure
- Project receivables
- Project contractual milestone status
- Current supplier delay
- Current manufacturing capacity
- Current executive decision queue
- Current value at risk
- Current protected value
- Current intervention deadline

## Demo rule

Until internal PARS data is supplied, UI components requiring these values must display:

- `DATA REQUIRED`
- `NOT YET QUANTIFIED`
- `INSUFFICIENT HISTORY`
- `INTERNAL SOURCE REQUIRED`

rather than invented numbers.

## Why

A CEO demo that contains fake financial/project numbers can demonstrate UI but destroys credibility when the product is evaluated against real PARS operations.

The first credible Demo therefore combines:

1. **Real PARS product portfolio data**
2. **Real PARS product imagery**
3. **Real internal project data when available**
4. **Explicit provenance for every decision-relevant value**
